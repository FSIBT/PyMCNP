# Automating Models, Runs, and Plots

Because PyMCNP inputs are Python objects, loops can build geometries that are tedious or impossible to type by hand, and the same script can plot the model and its results.
This example builds a 14.1 MeV point source above rough concrete ground with 441 iron discs of random thickness, tallies the neutron flux on a 2 cm mesh with `FMESH`, and plots both the setup and the result.
The model has 1334 cells and 1335 surfaces, all generated by two nested loops.

```{eval-rst}
.. note::
   The scripts write to ``examples/script_example_02_output``, which is ignored by git. Plotting needs ``pyvista`` and ``matplotlib``.
```

## Creating the Model

The ground is a 15 x 15 grid of concrete tiles whose heights are random; each tile gets an air cell above it so that every cell has a simple geometry.
The discs get the same treatment, each in its own air pillar.
Surfaces support `-surface`, `+surface` and `&`, so a cell geometry is written as `-body` or `-column & +body`.
The loops also keep the surfaces they create in lists (`tile_surfaces`, `disc_surfaces`), which the plotting script reuses.

```{eval-rst}
.. literalinclude:: ../../../examples/script_example_02_ground_model.py
   :language: python
```

Run it, and then run MCNP:

    python script_example_02_ground_model.py
    pymcnp run -p script_example_02_output/run script_example_02_output/ground.inp

## Plotting the Flux

`Meshtal.iter_tallies` reads the mesh tally and `to_dataframe` gives one row per voxel. The script reshapes it into an image of the flux and of its relative error.

```{eval-rst}
.. literalinclude:: ../../../examples/script_example_02_plot_flux.py
   :language: python
```

![Flux](../images/example_02_flux.png)

With 10^6 histories (`inp.nps`) the 10 cm grid of discs is visible as a pattern in the flux: the flux is highest below the source and falls off with distance, and the relative error (right) is mostly below 0.2 inside the disc array and grows towards the corners.
